# Techfest IIT Bombay — Landing Page

A responsive, no-3D, futuristic landing-page concept inspired by the visual energy of Techfest, IIT Bombay.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive styling and CSS artwork
- `script.js` — smooth interactions and scroll reveals

## Run locally
Just double-click `index.html` and open it in Chrome.

## GitHub
Create a new public repository on GitHub, then upload these three files plus this README. GitHub Pages can publish `index.html` directly.

## Notes
This is a concept/portfolio redesign, not an official replacement for techfest.org. Event names and themes are based on Techfest's public material; verify live event details on the official website before publishing.
